# Career Compass (CareerLens)

**CareerLens** is an advanced, AI-powered career profile analysis platform and interactive virtual career coach designed to help students, developers, and job seekers optimize their professional standing from a recruiter's perspective.

---

## 🚀 Product Vision

Job applications often fall into automated black boxes or fail to stand out due to misaligned keywords or vague portfolio descriptions. CareerLens bridges this gap by analyzing multiple facets of a candidate's professional profile against a target job description:

*   **Resume Parsing:** Evaluates format clarity, technical terminology, and impact statements.
*   **Portfolio Analysis:** Reviews project architectures, code presentation, and UI/UX standards.
*   **GitHub Integration:** Analyzes contribution history, repository activity, and code quality.
*   **Job Compatibility Matching:** Computes a precise readiness score and flags missing critical skills.

---

## 🛠️ Tech Stack & Architecture

Built with a modern, high-performance web development stack:

*   **Framework:** [TanStack Start](https://tanstack.com/start/latest) (Full-stack React framework with SSR)
*   **UI Library:** React with TypeScript
*   **Styling:** Tailwind CSS for a modern, minimalist design system
*   **Build Tool:** Vite & Nitro server engine
*   **Deployment:** Vercel (Serverless / Edge runtime)

---

## ✨ Core Features

1. **Multi-Source Profile Ingestion:** Seamlessly import or upload resume documents, portfolio URLs, and GitHub handles in one place.
2. **Recruiter-Grade Scoring Engine:** Generates comprehensive readiness metrics outlining strengths, vulnerabilities, and skill gaps.
3. **Actionable Recommendations:** Provides step-by-step guidance to tailor resumes and projects for specific job descriptions before applying.
4. **Interactive AI Career Coach:** An intelligent chat assistant to help practice interview responses, refactor resume bullets, and map out career growth strategies.
